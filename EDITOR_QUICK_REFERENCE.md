# ⚡ WYSIWYG Editor - Quick Reference Card

## 🎯 Quick Start
1. Open `/admin/posts/new` or `/admin/posts/<id>/edit`
2. Start typing in the editor area
3. Use toolbar buttons for formatting
4. Editor auto-saves every 3 seconds
5. Click "Create Post" or "Update Post" to publish

---

## ⌨️ Keyboard Shortcuts

```
Ctrl/Cmd + S          → Manual Save
Ctrl/Cmd + Shift + F  → Toggle Fullscreen
ESC                   → Exit Fullscreen
Ctrl/Cmd + B          → Bold
Ctrl/Cmd + I          → Italic
Ctrl/Cmd + U          → Underline
Ctrl/Cmd + K          → Insert Link
Ctrl/Cmd + Z          → Undo
Ctrl/Cmd + Y          → Redo
Ctrl/Cmd + V          → Paste (including images!)
```

---

## 🖼️ Image Upload Methods

### Method 1: Toolbar Button
- Click 📷 image icon
- Select one or multiple files
- Images upload and insert automatically

### Method 2: Drag & Drop ⭐ FASTEST
- Drag image files from desktop
- Drop into editor area
- Blue overlay appears when ready
- Release to upload

### Method 3: Copy & Paste
- Copy image from anywhere
- Press Ctrl+V in editor
- Image uploads automatically

### Method 4: Image Gallery
- Upload to gallery first (right sidebar)
- Click "Insert" button on any image
- Image appears at cursor position

---

## 🎬 Video Embedding

1. Click 🎬 video icon in toolbar
2. Paste video URL:
   - YouTube: `https://youtube.com/watch?v=...`
   - YouTube Short: `https://youtu.be/...`
   - Vimeo: `https://vimeo.com/...`
   - Dailymotion: `https://dailymotion.com/video/...`
3. Video embeds automatically
4. Responsive sizing applied

---

## 📊 Tables

### Create Table
1. Click table icon (📋)
2. Enter rows (e.g., "3")
3. Enter columns (e.g., "4")
4. Table inserted at cursor

### Edit Table
- **Right-click** any cell for menu
- **Tab** → next cell
- **Shift+Tab** → previous cell

### Operations Menu
- Insert Column (Left/Right)
- Insert Row (Above/Below)
- Delete Column/Row
- Merge Cells
- Unmerge Cells
- Delete Table

## ⚠️ Important Notes

### Content Validation
- ❌ Cannot submit empty post
- ❌ Cannot leave page with unsaved changes (without warning)
- ✅ All content auto-saved to browser
- ✅ Can recover from browser crash

### File Limits
- Image max size: **16 MB**
- Supported: JPG, PNG, GIF, WEBP
- Multiple uploads: Unlimited

### Browser Support
- ✅ Chrome, Edge, Firefox, Safari, Opera
- ❌ Internet Explorer not supported

## 🚨 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Image won't upload | Check size < 16MB, verify format |
| Autosave not working | Check browser console, try Ctrl+S |
| Content looks wrong | Use source view to check HTML |
| Table menu won't open | Right-click on cell, refresh if needed |
| Lost connection | Content saved locally, safe to refresh |

## 💡 Pro Tips

1. **Use drag-and-drop** for images - it's the fastest method
